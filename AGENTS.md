# Workspace Rules - Strava Runner Dashboard

## Core Rules for Agent Actions:

1. **Systematic Skill Selection**:
   - For ANY UI or styling task, consult and enforce:
     - `design-system-consistency`
     - `ui-ux-pro-max`
     - `frontend-design`
   - For debugging: consult `systematic-debugging`.
   - For architectural decisions: consult `brainstorming`.
   - For security & API keys: consult `security-and-hardening` and `credentials`.

2. **Commit Policy**:
   - Commits must be atomic, logical, and described in **simple English**.
   - **MANDATORY**: You must present the proposed commit message and changed files to the user and **WAIT FOR USER VALIDATION** before executing `git commit`.
